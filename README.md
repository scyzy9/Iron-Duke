#### 不列颠尼亚二三事 ####

伦敦也无非是这样。威斯敏斯特的梧桐烂熳的时节，望去确也象淡黄的夕云，但树下也缺不了成群结队的“中国留学生”的速成班，头顶上盘着金色卷发，形成一碗炸鱼薯条.
…
大概是物以希为贵罢。西班牙的白菜运往英国，便用透明袋套住，尊为“Pak Choi”；法兰西野生着的甜瓜，一到不列颠就请进超市，而且美其名曰“哈密瓜”.
…
从此就看见许多陌生的先生，听到许多新鲜的讲义。计算机学是四个教授分任的。最初是推理学。其时进来的是一个白瘦的先生，满头白散发，戴着眼镜，挟着一个笔记本。一将笔记本在讲台上，便用了缓慢而很有顿挫的声调，向学生介绍自己道：——

　　“我就是叫作Altenkrich的……。”
…
...那坐在后面发笑的是上学年不及格的留级学生，在校已经一年，掌故颇为熟悉的了。...这altenkrich先生，据说是形象太模胡了，有时竟会披头散发；冬天是一件旧外套，寒颤颤的，有一回上火车去，致使管车的疑心他是扒手，叫车里的客人大家小心些。
…

“去拿你们的课件来。”他慢慢地说...
这所谓“课件”，是指我开蒙时候所读的《算法、数据结构与效率》...
...我们忐忑着，拿了课件来了。他使我们坐在大讲堂的排椅前，教我们一页一页地看下去。我们担着心，一页一页地学下去...
　“给我读熟。背不出，就别想拿一等学位" ...我似乎从头上浇了一盆冷水...
...记得那时听人说，读《算法、数据结构与效率》比读《C++》、《Java》有用得多，因为可以知道算法的大概。知道算法大概，那当然是很好的...
...在百静中，我似乎头里要伸出许多铁钳，将什么“快速排序”“动态规划”之流夹住；也听到自己急急翻阅的声音发着抖，仿佛深秋的黄叶，在风中摆动似的。
